# PoC RCE — execute-code (pedagogiai) — bukti terkuat

Endpoint: `POST https://pedagogiai.smpm12gkb.sch.id/api/execute-code`
Header body: `{"language":"<py|js|php>","code":"..."}` — tanpa auth, CORS `*`, rate limit 60/min, PHP 8.3.35.

## Kesimpulan
`/api/execute-code` = proxy publik tanpa auth ke **self-hosted Judge0 1.14.0**.
- Code exec + shell (python/js) berjalan; PHP shell dimatikan oleh policy Judge0.
- Arbitrary file read di dalam container worker (`/etc/passwd`).
- Isolasi: uid ephemeral per-run, container `zag-srv02-ce-execution-worker`, **tanpa network egress** (DNS + TCP gagal).
- Bukan RCE langsung di app-server; eksekusi terkurung di sandbox Judge0. Risiko: abuse resource (judi/crypto/mining), enumerasi/baca berkas dalam worker, eskalasi via celah Judge0 1.14.0 bila ada.
